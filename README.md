### 📌 Overview

I design and benchmark lightweight, private, and localized software systems. My primary engineering focus revolves around hardware-accelerated local inference, autonomous agent workflows, and bridging efficient models to distributed backend infrastructure.

* ⚙️ **Core Focus:** Local inference pipelines, context window management, and hardware acceleration (NPU/iGPU/CPU).
* 🛠️ **Infrastructure:** Containerized backends, RESTful microservices, and asynchronous event streams.
* 🔬 **Current Research:** Quantization profiles (GGUF/AWQ), edge agent memory architectures, and RAG retrieval latency.
